# 万華鏡

## メモ
- オブジェクト
  - オブジェクトの形状を動的に変化させるために5つの変数（**素材形状変数**）を導入．生体情報を子の変数に割り当てることを想定
  - 素材形状変数を組み合わせて，万華鏡の模様の元となる**3種類の素材オブジェクト**を作成
  - 素材オブジェクトが動き回る**平面領域**を定義
  - 素材オブジェクトを指定数複製し，平面領域内のランダムな位置に配置
  - すべての素材オブジェクトに，動きの方向となる初期ベクトルを割り当てる
  - フレームが更新するたびに，ベクトル方向に素材オブジェクトを移動させる
  - 素材オブジェクトが，平面領域の端に到達すると移動方向ベクトルを反転させる
- インタラクション
  - **デバック用**: マウスの左クリック中ででフレームを更新する．マウスの右クリックですべての素材オブジェクトの移動方向ベクトルを反転させてフレームを更新する（逆再生）．
- UI
  - **デバック用**: オブジェクト形状を変化させるための変数を調整できるスライダーを左上に配置
